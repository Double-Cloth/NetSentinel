# ADR-008 基础工程与依赖选型

日期为 2026-11-13。状态为已用于基础代码，待团队人工评审。依据为既有架构及 WP-05 工程准备项，本记录由 Codex 辅助整理。

## 决策与理由

保留 `engine/`、`backend/` 两个独立 Go module，后端使用本地 `replace`。引擎仅依赖标准库，HTTP 使用 `net/http`，SQLite 使用 `database/sql` 与 `modernc.org/sqlite`。驱动支持纯 Go 构建，可在 Windows 与 Linux 容器使用同一实现。初期单连接串行访问，配合 WAL、外键与 busy_timeout，后续实际读写需求出现时接入独立查询连接。

前端采用 React、TypeScript、Vite，使用原生状态、fetch、CSS 与 History API。Vitest 执行基础测试，Geist 通过 `@fontsource/geist` 本地打包。构建插件提供 React 开发期刷新。首次页面以中文导航、真实健康检查和明确的模块状态建立可持续扩展入口。

Go 工具链最低版本为 1.27，Node.js 使用 CI 既定版本 24。依赖版本从官方 module proxy 和 npm registry 核验后精确锁定。后续更新提交依赖锁文件并执行完整验证。

## 实施边界与后续工作

Count 先实现严格规则编译、闭合窗口、阈值周期、完整证据与稳定指纹，为后续纵向业务提供真实引擎入口。当前编译器对其他检测类型返回 `RULE_TYPE_UNSUPPORTED`。正式版本编译必须提供匹配的 `spec_hash`，临时规则使用 version=0。

数据库迁移使用嵌入 SQL、事务和历史摘要校验，部署时通过单独命令执行。后端启动验证迁移版本，健康检查返回脱敏状态。基础阶段仅注册公开健康接口，身份表和角色契约为后续认证准备。

Docker Compose 使用一次性迁移容器、API、Nginx 静态资源与同源代理。API 以非 root 用户运行，数据保留在命名卷。容器镜像采用明确版本系列，基础镜像内容随上游维护可能更新，正式 Release 时按发布计划记录实际镜像摘要。

后续工作按 v0.1、v0.2、v0.3 推进。真实调研确认、架构签字、性能预算验收和人工放行由团队开展。
