# ADR-006 基础登录与会话

关联 #10、#33、FR-01 / UC-01。v0.1 通过本地命令在空数据库初始化首个管理员。登录、会话查询和注销使用既有身份表，继续由 #21 实现用户管理及角色变更时的会话撤销。

- 采用 `golang.org/x/crypto/bcrypt` v0.59.0（BSD-3-Clause），沿用前后端设计中验证过的 Go API 和已规划使用的模块版本。工作因子 12，初始化密码至少 12 个字符，最长 72 字节。依赖只进入 backend。见 [bcrypt 版本和许可证](https://pkg.go.dev/golang.org/x/crypto@v0.59.0/bcrypt)。
- 会话随机生成，SQLite 仅存其 SHA-256 摘要。Cookie 有效期 8 小时，带 HttpOnly、SameSite=Lax 及根路径，HTTPS 使用 Secure。会话查询读取用户当前状态。注销、登录成功审计与会话变更同事务。
- 登录按连接 IP 和用户名限制尝试，单进程同时最多执行两次密码验证。Compose 反向代理内的连接共享后端 IP 限额，部署侧可另行按客户端 IP 限速。服务不信任客户端转发头。
- 默认校验本机访问的同源 Origin。通过 HTTPS 代理或非本机访问时由部署者设置精确的 `NETSENTINEL_PUBLIC_ORIGIN`。认证写请求校验 Origin，注销额外校验由会话派生的 `X-CSRF-Token`。密码、Cookie、CSRF token 均不进入审计。
- 后端与 API 镜像使用 Go 1.27.4，覆盖扫描发现的 `net/http` 安全修复。见 [Go 安全公告](https://pkg.go.dev/vuln/GO-2026-6859)。
