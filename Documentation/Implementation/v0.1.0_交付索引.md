## 仓库文件

- `engine/`、`backend/`、`frontend/` 是独立构建和验证入口。Compose 与 `deploy/` 管理容器部署。
- `Documentation/Requirement/` 保存原始课程资料，`Documentation/Requirements/` 保存项目需求基线，`Documentation/Planning/` 保存详细规划，ADR 和实施记录分别位于 `Documentation/ADR/`、`Documentation/Implementation/`。
- `models/` 下的图源、渲染图和合成交接夹具用于课程交付及各工作包验收。根目录 `output/`、覆盖率、构建产物与本地运行目录由忽略规则管理。
