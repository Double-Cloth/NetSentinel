## 前后端交接

共用[现有接口设计](../Planning/04_前后端与数据实现设计.md#6-http-api-契约)的 data/error/request_id 信封、分页和错误码。HTTP 时间一律为 RFC3339 UTC、六位小数和 `Z`。204 无响应体。分页默认 `page=1&page_size=20`，最大 100，非法范围返回 422。下表配合 [TypeScript 契约](../../models/fixtures/v01-api.ts)使用。

| 接口路径（相对 /api/v1） | 权限 | 请求及成功响应 |
| --- | --- | --- |
| POST /auth/login | 公开，同源 Origin 校验 | 用户名和密码。200 返回用户和 CSRF token 并设置会话 Cookie |
| GET /auth/me、POST /auth/logout | 已登录 | 查询返回用户、角色、权限和 CSRF token。注销撤销会话并返回 204 |
| GET /log-sources、GET /log-sources/{id} | 已登录 | 200 返回 `Page<LogSource>` 或 `LogSource` |
| POST /log-sources | admin | `LogSourceCreate` 与幂等键。201 返回 `LogSource` |
| PATCH /log-sources/{id} | admin | `LogSourceUpdate` 含完整可编辑配置和 `row_version`。200 返回 `LogSource` |
| POST /log-sources/{id}/test、POST /log-sources/{id}/retry | admin | `SubmitCollection` 与幂等键。202 返回 `CollectionAccepted` |
| GET /log-sources/{id}/attempts、GET /log-sources/{id}/attempts/{attempt_id} | 已登录 | 200 返回 `Page<CollectionAttempt>` 或 `CollectionAttempt`。测试预览仅 admin 可读取 |
| GET /datasets/{id}/events | 已登录 | 200 返回按事件时间及原行序形成的 `Page<Event>` |
| GET /tasks/{id} | 已登录 | 200 返回 `AnalysisTask`，含固定快照与失败原因 |
| GET /alerts/{id}、GET /alerts/{id}/evidence | 已登录 | 200 返回 `Alert` 或按 ordinal 分页的 `Page<Evidence>` |
| POST /rules/validate | admin、analyst | `CountRuleSpec`。200 返回 `RuleValidation`，编译失败返回 422 和字段路径 |

创建来源时使用部署者配置的 `source_ref`，每个授权条目只允许绑定一个来源。来源创建后固定该绑定；编辑完整替换可编辑字段并条件更新版本。SSH RFC3164 使用显式四位年份和 IANA 时区，SSH RFC3339 与 Nginx combined 从原文提取偏移量。日常自动采集、测试和重试共用单源互斥。测试可用于停用源，重试要求启用且当前配置版本有效。禁用只阻止后续采集，旧任务和证据仍可查询。

已登录的写操作检查会话权限、Origin 和 CSRF，成功写操作的审计与写入同事务。幂等键作用域为调用者、HTTP 方法、对象路径与键，按规范请求摘要比对。认证与权限通过后优先返回已接收的同键同请求响应，确保刷新配置后仍可找回先前结果。载荷不同返回 409 `IDEMPOTENCY_CONFLICT`，旧版本返回 409 `VERSION_CONFLICT`，活动执行冲突返回 409 `SOURCE_BUSY`，重试停用源返回 409 `SOURCE_DISABLED`。参数正常但校验失败返回 422，`details[].path` 使用 JSON Pointer，空路径表示根对象。异步失败通过已接受尝试的终态及可展示错误返回，内部错误原文只留受控服务日志。

来源健康按停用、最近采集失败、积压、未采集、正常的顺序判定。积压表示最近成功后仍有超出本次读取预算的完整数据，或已错过计划时间且该次调度还未完成。正常空读更新最近成功，测试记录不改变来源健康。非 admin 共享脱敏状态及批次引用。设置页的 409 保留输入，刷新后由用户重试。失败状态展示上次成功时间、错误码，以及当前角色可用的恢复入口。

[交接夹具](../../models/fixtures/v01-api.json)包含失败来源、异步重试、自动任务快照、R-001 告警及证据、参数错误和版本冲突。散列是合成示例值，业务集成测试以实际规范化结果核验。运行时由真实服务产生响应。采集事务及版本边界见 [ADR-009](../ADR/009_v0.1_采集与分析契约.md)。
