## 前后端交接

共用[现有接口设计](../Planning/04_前后端与数据实现设计.md#6-http-api-契约)的 data/error/request_id 信封、RFC3339 UTC 微秒时间格式、分页和错误码约定。事件、规则与 Finding 以 `engine/event`、`engine/rule` 和 `engine/finding` 类型为准；引擎字段的时间为 UTC 整型微秒。窗口为闭区间 `[t-W,t]`，同时间事件按输入序号处理。引擎与 API 各自在边界转换，保留微秒精度。

| 接口路径（相对 /api/v1） | 权限 | 交接字段 |
| --- | --- | --- |
| POST /auth/login | 公开，同源 Origin 校验 | 帐号密码 → Cookie、用户、CSRF token |
| GET /auth/me、POST /auth/logout | 已登录 | 会话权限与 CSRF；注销撤销会话并返回 204 |
| GET /log-sources、GET /log-sources/{id} | 已登录 | id、name、enabled、format、health、last_success_at、next_collection_at、last_error、row_version |
| POST /log-sources、PATCH /log-sources/{id} | admin | 已授权 source_ref、format、timezone/year、interval_seconds、enabled；编辑携带 row_version |
| POST /log-sources/{id}/test | admin | 校验配置版本和幂等键，202 返回 attempt_id，结果包含连接状态及前 100 行解析预览 |
| POST /log-sources/{id}/retry | admin | 校验配置版本和幂等键，202 返回本次 attempt_id |
| GET /log-sources/{id}/attempts、GET /log-sources/{id}/attempts/{attempt_id} | 已登录 | 分页历史或单次结果，包含 phase、状态、错误码、断点及可访问批次引用；采样预览仅 admin 可读 |
| GET /tasks/{id}、GET /alerts/{id}/evidence | 已登录 | 固定快照、执行阶段与失败原因；证据按 ordinal 分页 |
| POST /rules/validate | admin、analyst | 合法规则返回规范化摘要；编译失败以 code/path 定位字段 |

列表状态区分未采集、正常、积压、失败和停用，失败页展示最后成功时间、错误码与允许的重试入口。已登录的写操作使用会话权限、Origin 和 CSRF；成功写操作审计进同一事务。API 样例见[交接夹具](../../models/fixtures/v01-api.json)，包含同源响应、失败来源和固定 R-001 警报的证据。夹具只用于开发和评审，运行时由真实服务产生响应。日志采集事务及版本边界见 [ADR-009](../ADR/009_v0.1_采集与分析契约.md)。
