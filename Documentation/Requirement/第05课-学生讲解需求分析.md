# 学生讲解需求分析

## 一、本课目标

分析模型定稿：类/行为完整，需求→用例→模型全链路可追溯

## 二、课堂流程（三段式）

| 环节 | 时长 | 内容 |
| --- | --- | --- |
| 教师引入 | 10′ | 回顾分析建模三张图的评审要点；强调"多一个视角少一处遗漏"。 |
| 学生讲解 | 8′×4–5 | 讲解完整分析模型：类的职责与协作、状态转换逻辑、关键交互顺序。 |
| 点评 | 20′ | 教员点评建模合理性与可追溯性：类图里的每个类能否指回需求条目？状态图有没有"到不了的状态"？ |
| 布置 | 10′ | 课后任务：进入概要设计。 |

## 三、课前准备（学生）

分析模型完善、追溯矩阵已更新

## 四、课后任务与提交物

- 需求分析规约定稿（评审签字）
- 分析模型定稿（类/状态/顺序图源文件合并）
- 追溯矩阵 v1：需求 ↔ 用例 ↔ 模型 全链路

## 五、GitHub 检查点

需求→用例→模型 全链路可追溯
